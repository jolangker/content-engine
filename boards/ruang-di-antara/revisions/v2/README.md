# Arsip board approved v2

V2 disetujui pada 17 Oktober 2026, dengan ilustrasi adegan/motion dominan, teks penekanan 0–5 kata, durasi sekitar 90 detik, dan target awal 14 frame.

Pada 18 Oktober 2026 pengguna memilih kembali ke visual v1 dengan isi lebih padat dan durasi sekitar 90 detik. Paket ini disalin sebelum penggantian, termasuk dokumen, sumber visual, ekspor, tiga studi, font, dan lisensi. Kesamaan sepuluh berkas utama diperiksa melalui hash sebelum penggantian.

Dokumen di arsip mempertahankan status serta rujukan pada saat v2 masih aktif. Status sekarang ada di [DIRECTION.md utama](../../DIRECTION.md); board aktif kini v1.1. Produksi yang sudah memilih v2 tidak diubah otomatis oleh pembaruan board.
