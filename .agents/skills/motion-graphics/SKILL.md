# Motion graphics for production scenes

This project-owned adaptation supplies a visual treatment to an existing scene or overlay. It works inside narrated and multi-scene films; the assigned scene window determines duration. HyperFrames owns the composition contract and shortform-production owns episode stages, approvals, audio, and export.

## Establish the scene contract

Read the saved brief/spec, inherited `frame.md`, and the relevant storyboard scene. Reuse the approved copy/data, scene ID and file, canvas/fps, start and duration, narration anchor words, caption keep-out band, and entering/ending state. Resolve only missing details that materially affect this visual. If no project or scene plan exists, let HyperFrames or shortform-production establish it first.

Work in the existing production's `video/` project and assigned composition path. Keep narration, full spoken captions, planned SFX, surrounding scenes, and timing under their owner's control. New project initialization, intake/pitch rounds, audio synthesis, publishing, and render approval stay in the owning workflow.

## Choose one visual module

Read only the module matching the scene's explanatory job. These are recipes: project style and timing take precedence over their sample palettes, duration estimates, effects, export formats, and standalone paths. A registry search, not a module's cached catalog list, establishes current availability.

| Visual job | Module |
| --- | --- |
| A phrase or title carries the beat | [Kinetic type](categories/kinetic-type/module.md) |
| One sourced number lands | [Stat](categories/stat/module.md) |
| Data comparison or progression | [Charts](categories/charts/module.md) |
| Places, regions, routes, geographic framing | [Maps](categories/maps/module.md) |
| Name bars, labels, callouts, social overlays | [Lower thirds](categories/lower-thirds/module.md) |
| A supplied/verified brand mark is revealed | [Logo reveal](categories/logo-reveal/module.md) |
| A real page or UI is demonstrated | [Webpage](categories/webpage/module.md) |
| A sourced article/headline is shown | [News](categories/news/module.md) |
| A sourced social post is shown | [Tweet](categories/tweet/module.md) |
| A real image's geometry explains the data | [Asset fusion](categories/asset-fusion/module.md) |

Use charts/stats only when they explain supported data. A mechanism or narrative scene that needs none of these treatments continues through HyperFrames' explainer/motion references; availability alone is not a reason to add a graphic.

For a 3D treatment or labels/overlays attached to a 3D scene, read the owner's [Three.js integration](../shortform-production/references/threejs.md) and load only the craft skills needed by the change. Keep camera/object state and projected annotations synchronized to the same scene time; the owner retains the full scene and episode workflow.

## Build in place

1. Derive the visual idea and word/visual cues from the existing storyboard scene. Return required planning changes to the owner to record there. For a new production, pose it through the owner's required storyboard pass; reuse an accepted pose when one exists.
2. Search the registry before hand-building a named look; customize a fitting block/component to the scene. Resolve required real assets through media-use and freeze them locally with provenance. An unavailable required asset is a gap to resolve, not a reason to fabricate it.
3. Read the [scene build contract](references/builder-contract.md), then author only the assigned composition or overlay. Inherit the board's fonts, color roles, medium, and fixed chrome. Develop motion across the assigned time window, aligned to measured narration; preserve the final reading state and the handoff to the next scene.
4. Inspect the scene in the assembled project at its reveal, readable hold, and final state, plus relevant seams. Check seek/reverse-seek behavior, data values, text fit at phone scale, and caption clearance. Use the owner's check/snapshot loop; broaden review when shared layout or timing changes.

Return the changed scene path, its time window, assets/registry items used, proof-frame locations, and any unresolved issue. The owner updates stage status and applies the existing review/render policy. This specialist adds no separate approval checkpoint and keeps episode audio decisions intact: ElevenLabs narration, existing media-use SFX first.
